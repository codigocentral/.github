# Código Central

We are a software company from São Paulo, Brazil, building tools for the people
who keep servers and code running. Founded in 2005, we build software for our
clients and open source the tools we use every day.

## Open source

| Project | What it does | |
|---|---|---|
| [Code Monitor](https://github.com/codigocentral/code-monitor) | Lightweight multi-server monitoring in Rust: one agent per server, a terminal dashboard and audit checks that point at real problems. AGPL-3.0. | [codemonitor.codigocentral.com.br](https://codemonitor.codigocentral.com.br) |
| Code Terminal | A GPU-accelerated terminal with splits, persistent sessions, a built-in browser and hooks for AI coding agents. | Coming soon |

Contributions are welcome. Each project explains how in its `CONTRIBUTING.md`.
